The Autodok System
The Autodok is a web-based management system for an automotive care shop. 
It helps the admin track job orders, manage car services, monitor parts inventory, handle technician staff, 
and view business income reports — all in one place.

Features

* Dashboard
* Services
* Inventory
* Report

Technologies Used

* HTML
* CSS
* JavaScript
* PHP
* MySQL
